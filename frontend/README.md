# 🏥 Vital Care — Premium Clinic Website

Vital Care is a modern premium healthcare website built using the latest React ecosystem with Apple-style UI/UX, smooth animations, dark mode support, premium glassmorphism effects, AI chatbot, appointment booking system, and responsive design.

# 🚀 Features

- Premium Apple-style UI
- Dark / Light Mode
- Framer Motion Animations
- Floating WhatsApp Support
- AI Healthcare Chatbot
- Appointment Booking UI
- Scroll Progress Indicator
- Responsive Mobile Design
- Glassmorphism Effects

- Modern Routing Architecture
- SEO Friendly Structure
- Reusable Components
- Clean Folder Structure

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/talibaziz0786-dot/Vitalcare-clinic.git
```

---

## Open Project

```bash
cd vital-care
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```
